# olympic-park-access-guide
올림픽공원 주차장과 공연장 입구까지의 이동 경로를 안내하는 웹 서비스


# 올림픽공원 주차·이동 안내

올림픽공원 공연을 보러 가는 관람객이 출발 전에 **어디에 주차할지, 주차장에서 공연장 입구까지 어떻게 이동할지** 확인하는 웹 서비스입니다.

## 기획 배경

낯선 공연장에 차로 갈 때는 주차 자리가 있는지부터 걱정됩니다. 주차할 수 있더라도 실제로 이용할 출입구까지 얼마나 걸어야 하는지, 도중에 계단이나 턱이 있는지에 따라 선택이 달라집니다. 이 프로젝트는 장애인 관람객의 이동을 중심으로, 오래 걷거나 계단을 오르기 어려운 관람객도 자신에게 맞는 주차장과 이동 경로를 고를 수 있도록 돕습니다.

## 첫 버전에서 만들 기능

- **공연 선택** · 관람할 공연을 고르면 공연장과 주변 주차장 후보를 보여줍니다.
- **주차장 비교** · 주차장에서 이용할 출입구까지의 거리와 확인된 계단·턱·경사로 위치를 지도와 글로 안내합니다.
- **장애인 전용 주차구역 보기** · 전용구역의 위치, 설치 면수, 이용 조건을 확인할 수 있습니다.
- **주차 현황 조회** · 공개 데이터에서 확인한 범위의 주차 현황을 보여줍니다. 주차장별 실시간 잔여 대수는 API가 해당 값을 제공할 때 표시합니다.

## 공공데이터 활용 계획

- **올림픽공원 공연정보** · 공연과 공연장을 연결합니다. [공공데이터포털](https://www.data.go.kr/data/3037877/openapi.do)
- **올림픽공원 실시간 주차현황** · 응답의 주차 대수가 무엇을 의미하는지, 주차장별 값을 제공하는지 확인합니다. [공개 API 안내](https://www.ksponco.or.kr/pubData/64?mid=a10106020000)
- **올림픽공원 주차장 이용 안내** · 장애인 전용 주차구역의 설치 면수를 확인합니다. [공식 안내](https://www.ksponco.or.kr/board.es?act=view&bid=0046&list_no=82568&mid=a10301000000)

장애인 전용 주차면 수는 `설치 면수`로 표시합니다. 빈자리 정보와 계단·턱 여부를 확인하지 못한 구간은 `미확인`으로 표시합니다.
